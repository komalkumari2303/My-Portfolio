QUE-1: WHAT IS COMPUTER?
Ans. Computer is an electronic machine.It accepts the data from users,then process it and afer that it provides output.

QUE-2: HOW MANY COMPONENTS OF COMPUTER?
Ans. There is two components of computer:-
1.Hardware
2. Software

QUE-3: WHAT IS HARDWARE WITH THEIR EXAMPLE?
Ans. All the physical component of the computer which you can see or touched is called hardware.

For example: Keyword,Mouse,CPU,Monitor etc.

QUE-4: WHAT IS SOFTWARE WITH THEIR EXAMPLE?
Ans. Software is a set of programs orinstruction which tell the computer what to do. Software cannot be seeing or touched.

For example: MS Word,MS Excel,Windows,and paint etc.

There are two types os software

1. System Software
2. Application Software
